GreenGetaway

A sustainable tourist guide to Copenhagen. Find the greenest attractions on a map, see how each one scores, and log the places you visit with a photo.

Compare. Switch between the 2023 course app and the 2026 redesign above the phone. Both are the real apps running in the browser. Log in with any email and password. Location and the camera only ask for permission when you use them.

Open the 2026 app Open the 2023 app View the code See the design system
  • Built with React Native and Expo for the course Programming Mobile Applications at ITU in 2023
  • Audited and redesigned in 2026: eco score bands with a legend, score pins, a ranked list of all 13 places, and visits saved as one record each
  • On the web, the native map is replaced by Leaflet, and sign-in is skipped, so no account or data is stored
