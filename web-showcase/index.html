GreenGetaway

A sustainable tourist guide to Copenhagen. Find the greenest attractions on a map, see how each one scores, and log the places you visit with a photo.

Demo. This is the original app's code running in the browser. Log in or sign up with anything, or with nothing at all, to get in. The map, the leaderboard and the add flow all work. Location and the camera only ask for permission when you use them.

  • On the web, the native map is replaced by Leaflet, showing the same attractions and pins
